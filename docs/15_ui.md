# Задание 15. Пользовательский интерфейс

**Автор:** Омаров Марлен Еркешович, SIS-2304

Django-шаблоны + Bootstrap 5.3 + Bootstrap Icons. Библиотеки лежат в `static/vendor/` (с лицензиями MIT) — приложение
работает без интернета, в том числе на защите. Каркас — боковое меню (раздел 9.2): Dashboard, Проверка SMS,
Проверка URL, История, Статистика, Профиль, Выход; на ширине < 768 px меню открывается кнопкой ☰.

## 1. Страницы

| Страница | Адрес | Шаблон | Как работает |
| :--- | :--- | :--- | :--- |
| Вход / регистрация | `/login/`, `/register/` | `accounts/login.html`, `register.html` | серверные формы с CSRF; ошибки под полями |
| Dashboard | `/` | `dashboard/home.html` | задание 17 |
| Проверка SMS | `/check/sms/` | `analysis/check_sms.html` | `fetch` → `/api/v1/check/sms/` без перезагрузки |
| Проверка URL | `/check/url/` | `analysis/check_url.html` | `fetch` → `/api/v1/check/url/` |
| Результат | `/checks/<id>/` | `analysis/check_detail.html` | данные через `json_script`, тот же рендер |
| История | `/history/` | `analysis/history.html` | задание 16 |
| Статистика | `/stats/` | `dashboard/stats.html` | задание 17 |
| Профиль | `/profile/` | `accounts/profile.html` | задание 16 |

Без входа все страницы, кроме входа и регистрации, перенаправляют на `/login/?next=…` (ФТ-1.6).

## 2. Требования задания

| № | Требование | Реализация (`static/js/app.js`) |
| :--: | :--- | :--- |
| 1 | Поле SMS, счётчик n/1000, «Проверить сообщение», «Очистить», 3 примера | счётчик обновляется на `input`, при > 1000 краснеет; примеры — безопасное, подозрительное, мошенническое (искусственные) |
| 2 | Поле URL, «Проверить ссылку», подсказка | «Ссылка не открывается: анализируется только её структура» |
| 3 | Индикатор загрузки, защита от двойной отправки | кнопка блокируется, спиннер, надпись «Анализ…»; флаг `busy`; на сервере повтор за 10 с не создаёт запись |
| 4 | Блок результата | бейдж категории, заголовок, шкала Risk Score 0/35/70/100, уровень, P_sms и P_url, признаки, объяснение, рекомендация, дисклеймер, дата, версии моделей |
| 5 | URL неактивным текстом | `<span>` вместо `<a>`, домен выделен `<mark>` (ФТ-3.10) |
| 6 | Только `textContent` | функция `el()` создаёт узлы через `createElement`/`createTextNode`; `innerHTML` для данных не используется |
| 7 | Цвет не единственный носитель смысла | у каждого бейджа иконка + текст: ✓ «Безопасное», ⚠ «Подозрительное», ⊗ «Мошенническое» |
| 8 | Адаптивность 360 / 768 / 1366, контраст ≥ 4,5:1 | см. разделы 3–4 |
| 9 | Ошибки рядом с полем на русском | ответ API `error.message` выводится под полем (`role="alert"`, `aria-invalid`); при отсутствии модели — предупреждение и заблокированная кнопка |

Проверка XSS: текст `<script>alert(1)</script>` показывается как текст на странице проверки, в истории
(автоэкранирование Django) и на странице результата (`json_script` кодирует `<` как `<`) — тесты
`test_xss_payload_returned_as_data`, `test_history_escapes_xss`.
